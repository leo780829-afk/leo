# 小島辦公室

依 BRIEF.md 完成的原創單頁像素 AI 辦公室。以暖綠、奶油與木質色呈現俯視辦公空間，包含三個部門工作島、部門牌、九個專屬座位、書櫃、佈告欄、咖啡機、沙發與植栽。

## 啟動

在本資料夾執行 `python3 -m http.server 8080`，瀏覽 `http://localhost:8080`。也可使用 `npm start`。頁面本身無框架、無建置步驟。

執行時依序 fetch `../../office/status.json`、`./status.json`。前者失敗或格式無效便讀取本地範本，每 60 秒更新；右上方顯示資料的 `asOf`。請使用 HTTP 伺服器開啟，直接以 file:// 開啟會受到瀏覽器 fetch 限制。若要讀到上層 office 資料，部署的 HTTP 根目錄須涵蓋該路徑。

## 完成內容

- 原創 Canvas 像素地圖、家具與角色，角色具上下左右方向及雙幀走路動畫。
- `light=working` 的員工在專屬座位面向電腦；`waiting`、`idle` 員工循環閒晃、回座位玩電腦、走近閒置同事聊天，並顯示泡泡。
- BFS 格子尋路，牆面、桌子、沙發、植栽及其他家具共用阻擋格，移動依相鄰格進行。
- 點選角色或可鍵盤操作的員工名冊，底部遊戲式對話框顯示姓名、state、title、screen、lines、updated；關閉後返回佈告欄。
- 三部門完整名冊、即時狀態統計、動畫暫停／繼續。
- 桌機雙欄、手機直欄；手機地圖可水平滑動，完整保留地圖，名冊可直接找到所有同事。
- 自帶支援繁體中文的像素字型，頁面啟動後無需向外部 CDN 載入素材。

## 素材與授權

地圖、家具、人物與所有像素插畫均以程式自行繪製，未使用任天堂或其他遊戲素材。

字型採用 [Fusion Pixel Font／縫合像素字體](https://github.com/TakWolf/fusion-pixel-font)，12px proportional zh_tw，版本 2026.10.25，以 SIL Open Font License 1.1 提供；字型及原始授權保留於 `assets/`。下載來源為該專案 GitHub Releases。

## 驗證

`npm install` 後執行 `npm test`。測試使用系統 `/usr/bin/google-chrome` 與 Playwright；若系統 Chrome 位於其他路徑，需調整 `test.cjs` 的 executablePath。

已以無頭 Chrome 檢查 1280×800 桌機與 390×844 手機，完整頁面截圖分別存於 `shots/desktop.png` 與 `shots/mobile.png`。確認中文顯示、9 位員工、範本備援、點擊對話、暫停、手機無整頁水平溢出，以及約 90 秒模擬內三種活動都有發生，家具碰撞為 0。地圖自身的水平滑動是手機預期操作。

## 已知問題

- 為保留人物與家具細節，手機地圖需要左右滑動；整頁需垂直捲動閱讀完整名冊與對話。
- 員工之間沒有互相阻擋，因此狹窄走道相遇時可能短暫重疊；不會穿過家具或牆面。
- 目前座位及部門按照題目九位員工配置；新增不同 id 的員工需要擴充座位表與名冊。
- 當主要資料 URL 不在 HTTP 伺服器範圍內時，第一次請求會出現預期的 404，隨後自動使用本地範本。
