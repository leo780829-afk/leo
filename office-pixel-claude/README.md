# 像素 AI 辦公室

寶可夢 GBC/GBA 風格的俯視像素辦公室。單頁網頁，純 HTML + CSS + Canvas 2D + 原生 JavaScript，無任何框架或建置流程，開啟 `index.html`（建議透過本機伺服器）即可執行。

## 執行方式

因為頁面會用 `fetch` 讀取 `status.json`，用瀏覽器直接開啟 `file://` 可能會被瀏覽器的 CORS 規則擋下，建議在本資料夾起一個簡易伺服器：

```bash
python3 -m http.server 8731
# 瀏覽器開 http://localhost:8731/index.html
```

資料讀取順序：先嘗試 `../../office/status.json`，失敗（找不到檔案 / CORS / 404）就自動改讀同資料夾的 `status.json`。畫面右上角與對話框內都會顯示資料的 `asOf` 時間，每 20 秒會重新抓一次 `status.json` 更新畫面。

## 美術素材來源與授權

- **角色、家具、地板、招牌等所有像素圖，全部由 `app.js` 以 Canvas API 逐像素程式繪製產生**（見 `drawCharFrame`、`drawDesk`、`drawSofaRow` 等函式），沒有使用任何任天堂或第三方圖檔，確保原創、無版權疑慮。每位員工有獨立配色（髮色、膚色、上衣、褲子、眼鏡/領帶/髮飾等）以利辨識，四方向（上下左右）各 2 張走路影格，程式即時合成。
- **像素字型**：[Vonwaon Bitmap Font（凰點陣體）16px](https://timothyqiu.itch.io/vonwaon-bitmap)，作者 Haoyu Qiu，**CC0 1.0 Public Domain** 授權，支援繁體中文、日文假名等。字型檔放在 `assets/fonts/VonwaonBitmap-16px.ttf`（透過 jsDelivr 鏡像的 npm 套件 `@fontpkg/vonwaon-bitmap-16px` 下載，與 itch.io 官方版本內容相同），授權說明一併存於 `assets/fonts/VonwaonBitmap-16px-README.md`。依作者聲明可自由用於任何專案、不需授權同意，本專案仍於此致謝原作者。

## 已完成功能（對照 BRIEF.md）

- 俯視像素地圖：24×16 格（16px/格），依部門分成三個工作島（管理部／投資研究部／內容工作室，各有地板色塊＋立牌），外加走道與休息區（沙發 3 格＋咖啡機＋多盆植物＋窗戶＋裝飾門）。
- 9 位員工皆有自己的座位與電腦螢幕：美美、天睿顧問Alfred（管理部）；以恆、子睿、承遠、書妍（投資研究部）；語彤、若晴、品安（內容工作室）。
- 行為邏輯（依 `status.json` 的 `light` 欄位驅動）：
  - `working`：固定坐在自己座位，面向電腦，螢幕顯示綠色「工作中」光效。
  - `waiting` / `idle` / 其他：會在「閒晃走動」「回座位假裝打電動（粉紅光效＋🎮 泡泡）」「走到沙發坐下休息（☕ 泡泡）」「走到另一位同樣有空的同事旁邊聊天（💬 對話泡泡）」四種行為間隨機切換，並以 BFS 網格尋路避開牆壁／桌子／沙發／咖啡機／植物／立牌等家具，不會穿模。
  - 聊天採全域配對機制：每隔數秒檢查目前「有空」的同事，隨機兩兩配對、各自走到對方附近、面對面聊天數秒後各自解散，冷卻一段時間才會再被配對。
- 點擊／點觸任一員工（含走動中的）會跳出寶可夢式對話框，顯示姓名＋職稱、狀態、`sub`、完整 `screen` 內容、`lines` 標籤，以及員工 `updated` 時間與整份資料 `asOf` 時間。
- 每位員工頭上有常駐標籤（顯示 `title`，依 `light` 上色：綠＝工作中／黃＝等待決定／灰藍＝閒置／紅＝異常），畫面下方另有圖例列說明顏色與圖示意義。
- RWD：同一份地圖同時支援手機 390×844（直向）與桌機 1280×800（橫向），依可用空間自動等比例縮放並保持像素銳利（`image-rendering: pixelated`），兩種尺寸皆以無頭瀏覽器截圖存於 `shots/`（`shots/mobile_390x844.png`、`shots/desktop_1280x800.png`）。
- 交件前使用 Playwright + 系統內建 Chromium 做了多輪無頭瀏覽器驗證：長時間（45 秒以上）狀態取樣確認「閒晃／玩電腦／聊天／坐沙發／工作」五種行為都會實際發生且會輪替；手機尺寸下模擬觸控 tap 可正確叫出對話框；確認繁體中文（含職稱、screen 全文、lines 標籤）皆正常顯示、無亂碼。

## 已知問題

1. **手機直向畫面留白較多**：辦公室地圖本身是偏橫向的比例（24:16），在 390×844 的直向手機上寬度先被撐滿，上下會留白。目前作法是把地圖靠上對齊、留白處放一個狀態圖例（顏色／圖示說明）填補版面，但仍不是「滿版」畫面，屬於設計取捨而非錯誤。
2. **頭上標籤／對話泡泡偶爾會與部門立牌或鄰近同事的標籤視覺重疊**：當員工剛好站在自己座位、或多位同事擠在沙發／聊天時，16px 小格子的垂直空間有限，文字泡泡偶爾會貼得很近甚至小範圍重疊，但不影響點擊互動與對話框本身的正確性。
3. **員工之間不會互相避讓**：尋路只會避開家具與牆壁，不會把「其他正在走動的同事」當成障礙物，所以偶爾會看到兩人路徑短暫交疊（不會卡住，只是視覺上穿過彼此）。
4. **`../../office/status.json` 路徑依賴外部目錄結構**：此路徑是否存在取決於部署時的資料夾安排；本機單獨測試（如本 README 的執行方式）一定會先打一次這個路徑失敗（可在瀏覽器 console 看到一次 404 是正常現象），再自動 fallback 回同資料夾的 `status.json`，結果正確。
5. 狀態資料採輪詢（每 20 秒）更新，不是即時推送；若 `status.json` 在這之間變動，畫面會在下一次輪詢後才反映。
6. 像素字型的美術來源：Vonwaon Bitmap 作者本人在 itch.io 頁面聲明全字型 CC0，但其字模是基於開源專案 BitmapFont 調整而來，社群上曾有留言對底層字模的原始版權归属提出疑問；本專案基於作者本人的 CC0 聲明使用，若未來有疑慮可替換成其他已確認授權的中文像素字型。
